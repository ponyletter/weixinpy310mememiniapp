# 表情包小程序开发前置核心配置清单 (Checklist)

在正式接入编码与上线前，建议根据此清单逐项核验所有必要凭据、参数与支付授权，避免中途阻塞。

---

## 一、基础凭据清单 (Credentials)

| 配置项名称 | 字段名 (环境变量) | 获取位置 / 路径 | 填写状态 |
| :--- | :--- | :--- | :--- |
| **小程序 AppID** | `WX_APPID` | 微信公众平台 ➔ 【开发管理】 ➔ 【开发设置】 | `[待填，如 wxef6c...]` |
| **小程序 AppSecret** | `WX_APPSECRET` | 微信公众平台 ➔ 【开发管理】 ➔ 【开发设置】 | `[待填，32位密钥]` |
| **微信商户号** | `WX_MCHID` | 微信商户平台 / 微信公众平台 ➔ 【微信支付】 | `[待填，如 1750295708]` |

| **服务端口** | `PORT` | 服务器预留端口 (例如 8290) | `8290` |

## 二、微信小程序虚拟支付配置 (Virtual Payment)

针对表情包小程序中的**VIP会员、积分充值、去水印制作道具、特色高清表情包解锁**等虚拟道具，需使用微信官方提供的 `wx.requestVirtualPayment`。

### 1. 支付核心参数
| 参数名称 | 环境变量名 | 获取位置 | 避坑提醒 |
| :--- | :--- | :--- | :--- |
| **支付应用 ID (OfferID)** | `WX_OFFER_ID` | 微信公众平台 ➔ 【功能】 ➔ 【虚拟支付】 | 务必与 AppID 绑定匹配，否则报 `OFFER_ID_INVALID` |
| **现网 AppKey** | `WX_OFFER_APPKEY` | 虚拟支付后台 ➔ 基本配置 ➔ AppKey 管理 | 生产环境务必使用【现网AppKey】，勿与沙箱混淆 |
| **沙箱 AppKey** | `WX_OFFER_SANDBOX_KEY` | 虚拟支付后台 ➔ 基本配置 ➔ 沙箱环境 | 用于沙箱充值模拟测试 |
| **环境模式 (env)** | `WX_PAY_ENV` | 前端代码参数：`0` (现网生产), `1` (沙箱测试) | 微信开发者工具内模拟支付常受限，**强烈建议在真机调试/体验版上测试** |

### 2. 发货回调（额度到账的必要条件）

- 在虚拟支付“基础配置/发货推送”中开启道具发货通知；回调地址填写
  `https://meme.tg-cc755.cn/api/pay/notify`，不要填写仅提供其他业务的 `apiwx.tg-cc755.cn`。
- 服务端订单先记录为 `PENDING`，只有收到 `TRANSACTION.SUCCESS` 并通过现网 AppKey 的
  `payEventSig` 验签后才增加额度；前端支付弹窗的 success 不能直接当作到账凭据。
- 回调响应必须包含 `{"returnCode":"0","data":"ok"}`，否则平台会认为发货失败并重试。
- 使用生产 AppKey 计算签名时，`payload` 必须使用平台推送的原始 JSON 字符串，不能先解析后重新序列化。

### 3. 授权绑定关键点
- 登录微信公众平台 ➔ 【支付与交易】 ➔ 【微信支付】 ➔ 【商户号管理】；
- 确认当前商户号已完成授权并处于【已授权/正常】状态，否则前端调用将报错 `errno: -15001 小程序appid和虚拟支付商户号未绑定`。

## 三、表情包道具 / 充值配置示例 (Excel 批量导入规范)

虚拟支付道具在后台配置支持 Excel 批量导入。**极其重要的避坑经验：道具金额单位为【分】**。

| 道具ID (`product_id`) | 道具名称 (`name`) | 价格(分) (`price`) | 实际显示价格 | 道具类型 | 描述 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `goods_coin_100` | 100 萌趣金币 (测试) | 100 | 1.00 元 | 消耗型代币 | 适合作为 1 元真机联调测试项 |
| `goods_coin_600` | 600 萌趣金币 | 600 | 6.00 元 | 消耗型代币 | 解锁 10 套高清付费表情 |
| `goods_coin_1800` | 2000 萌趣金币 (送200) | 1800 | 18.00 元 | 消耗型代币 | 热门充值档位 |
| `goods_vip_month` | 月度斗图 VIP 会员 | 1200 | 12.00 元 | 权益/服务 | 尊享无限制下载与高清去除水印 |
| `goods_vip_year` | 年度尊享 VIP 会员 | 9800 | 98.00 元 | 权益/服务 | 全年无限畅享所有表情包与新梗推送 |

> ⚠️ **单位踩坑高发提示**：
> 在官方后台 Excel 模板中，若输入 `8800`，代表的是 **88.00 元**（8800 分）。若误理解为 8800 元，会导致价格被放大 100 倍！上传前请严格复查。
