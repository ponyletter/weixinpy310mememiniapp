# 微信小程序官方提审全通关指南与通用文案模版（首次提交/首发版本专用）

> **适用场景**：小程序 **首次提审发布（v1.0.0 首发版本）** 与常规版本提审。  
> **核心原则**：**如实描述、类目与实际功能一致、同一版本对所有用户展示一致、开箱即测**。本指南以微信官方现行规则为准，历史知识库中的“暗门/审核后热切换”方案已废止。

---

## 📋 一、 提审后台核心表单（首次提审直接复制粘贴）

在 **微信公众平台 (mp.weixin.qq.com)** ➔ **版本管理** ➔ **提交审核** 时，请严格按照以下内容填写：

### 1. 服务类目选择（决定是否需要前置资质）
* **个人主体当前适用类目**：
  * **一级类目**：`工具`
  * **二级类目**：`图片处理`
  * 官方适用范围：图片/音频/视频制作、剪辑；个人主体无需额外资质。
* ⚠️ **绝对不要选择的雷区类目**：
  * ❌ *文娱 - 表情/动态表情*（部分主体会被强制卡版权证明、动漫 IP 授权书）；
  * ❌ *社交 - 社区/论坛*（强制要求《增值电信业务经营许可证》与人工审核团队资质）；
  * ❌ *资讯/医疗/金融类目*（强制要求各类前置政府批文）。

| :--- | :--- | :--- |

| **相机/相册读取（选填）** | 上传图片或视频 | 用户在“极速二创”或“图片参考”中主动上传本地图片作为制作底图 |

### 5. 审核模式与后续版本

- 当前提审版本和发布后的实际功能必须保持一致，审核模式面向所有用户，不区分审核员。
- 发布后不得通过服务器配置直接开放本次未提交审核的 AI 生成功能。
- 未来恢复 AI，须先满足对应主体、服务类目、算法备案/合作协议和显著标识要求，再作为新版本重新提交审核。
- 服务器仅保留 SSH 本地切换脚本，公开的审核模式切换接口已删除；关闭本地处理模式还要求显式提供 `--reviewed-release` 确认参数。

## 🛡️ 二、 首次提审避坑与合规红线保障

### 1. 为什么必须强调“不涉及社区/社交”？
微信对“社交 - 社区/论坛”监管极其严格，如果审核员误以为用户可以“公开发帖让所有人看到”，就会强制要求提供省通信管理局颁发的《增值电信业务经营许可证（ICP/EDI）》以及信息安全审核制度。
* **我们小程序的真实设计**：表情合集和制作结果仅保存在用户个人名下或通过点对点分享卡片转发，**没有公开信息广场与评论互动区**。在版本描述中明确说明“不涉及社区发帖”，能彻底免除该项质疑。

### 2. 为什么必须强调“不涉及第三方版权动漫 IP”？
如果选了“文娱-表情包”，微信会要求提供全套版权登记证书或授权书。
* **我们小程序的真实设计**：属于“图片文字排版与动图渲染工具”，定位类似于“美图秀秀/印章生成器”。明确声明“不涉及第三方受保护版权动漫 IP”，合法归入【工具 - 图片文字】。

### 3. iOS 虚拟支付隔离提示
* 首次提审时，新用户进入即享有充足的免费制作额度与每日签到奖励，审核员可以直接完整跑通制作与保存闭环；
* 审核测试说明中明确提示“无需付费即可完整体验闭环”，消除审核员对付费合规性的顾虑。

## 🚀 四、 首次提审前最后自检清单 (Checklist)

- [ ] **后台基础信息**：小程序头像、名称、服务类目 `工具 - 图片处理` 已填好。
- [ ] **用户隐私保护指引**：已逐项声明相册/相机、OpenID、头像昵称和生成素材的用途。
- [ ] **服务器域名**：request/uploadFile/downloadFile 合法域名均已配置并通过 HTTPS 校验。
- [ ] **体验闭环**：新用户无需付费即可完整测试上传、制作、保存、删除和账号注销。
- [ ] **内容安全**：用户文字和图片在服务端再次调用微信内容安全接口，不只依赖前端预检。
- [ ] **版本一致**：现网已保持本地图片处理模式；发布后不热切换未审核 AI 功能。
- [ ] **人工后台项**：完成隐私指引、服务类目、版本描述、测试说明并上传体验版自测。
